# Мир больших денег

Одностраничный сайт настольной игры «Мир больших денег».

- `index.html` — страница сайта
- `img/art/` — арт с крышки коробки (первый экран)
- `img/box/` — коробка игры
- `img/cards/`, `img/companies/` — карты и карты компаний
- `img/parts/` — планшет игрока и купюры
- `img/letters/` — сканы писем партнёров (контакты закрыты)
- `files/` — PDF для скачивания: правила и файлы для печати прототипа

Цифры игры (игроки, возраст, время) — в `index.html`, блок с комментарием «ЦИФРЫ ИГРЫ».
