# Мир больших денег

Одностраничный сайт настольной игры «Мир больших денег».

- `index.html` — страница сайта
- `img/` — изображения карт, компаний и компонентов; `img/letters/` — сюда класть сканы писем партнёров
- `files/` — PDF для скачивания (правила и файлы для печати прототипа)

Как добавить письмо партнёра: см. комментарий в `index.html` в разделе «Письма партнёров».
